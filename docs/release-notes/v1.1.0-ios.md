## 3) Bu sürümde neyin değiştiği (dahilî)

Kullanıcıya görünen değişiklikler için `v1.1.0-android.md` dosyasındaki tam listeye bak.
iOS'a özgü olanlar:

- **Expo SDK 53 → 57 yükseltmesi.** Apple 26 Temmuz itibarıyla Xcode 26 ile derlenmiş
  binary şartı koydu (hata 90725). SDK 53'ün React Native sürümü Xcode 26 ile
  derlenemiyordu; yükseltme zorunluydu.
- Minimum iOS sürümü 15.1 → **16.4** yükseldi (SDK 57 şartı). iOS 15 kullanıcıları
  bu sürümü alamayacak.
- Başlıktaki üst boşluk artık gerçek güvenli alan değerinden okunuyor; öncesinde
  Android'e özgü bir API kullanıldığı için iOS'ta 0 dönüyordu.
